## 3. รู้จักของบนบอร์ด

  --------------------------------------------------------------------------------
  อุปกรณ์                   ใช้ใน Python                      ใช้ทำอะไร
  ----------------------- -------------------------------- -----------------------
  จอสัมผัส                  `ui`                             แสดงข้อมูลและรับการแตะ

  RGB 16×8                `rgbmatrix`                      แสดงสถานะให้เห็นจากไกล

  Radar BGT60TR13C        `sensors.radar()` /              ตรวจคน/ระยะ
                          `sensors.radar_range()`          

  Microphone              `mic.start()` / `mic.stats()` /  ตรวจเสียง
                          `mic.level()`                    

  IMU BMI270              `sensors.bmi270.motion()`        ตรวจการสั่น/การเคลื่อนไหว

  VR1--VR4                `pots.read(0)`--`pots.read(3)`   ตั้ง threshold หรือจำลองค่า

  SW5 / SW6               `buttons.pressed(0)` /           เปิด/ปิด, รับทราบ, สั่งงาน
                          `buttons.pressed(1)`             

  Speaker                 `ui.tone()`                      เสียงเตือน

  Wi-Fi + MQTT            `wifi` / `mqtt`                  รายงานและรับคำสั่ง
  --------------------------------------------------------------------------------

> **ปุ่ม:** SW5 = ปุ่มล่าง = `buttons.pressed(0)` · SW6 = ปุ่มบน =
> `buttons.pressed(1)`\
> อย่าใช้ชื่อ `SW2` บนฐานบอร์ดเป็นปุ่มของกิจกรรมนี้ เพราะ SW2 เป็นสวิตช์ตัดไฟ
