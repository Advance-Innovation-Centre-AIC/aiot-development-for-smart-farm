## Code Quest — อ่าน · เดา · แก้ · เติม · สร้าง

ทุกกิจกรรมมีโจทย์เป็นขั้น ทำเรียงจากระดับ 1 ขึ้นไป ทำได้ถึงไหนก็ได้แค่นั้น
**โจทย์หลัก (มีเฉลยในคาบ)** = ทุกกลุ่มควรทำให้ได้ มีเฉลยให้เปิดดูได้ในคาบ ไม่มีใครติดค้าง
**โจทย์เพิ่ม (โบนัส เฉลยคาบหน้า)** = ทำเพื่อสนุกและเก็บแต้ม ไม่มีผลต่อเกณฑ์ผ่านคาบ เฉลยอธิบายในการพบกันครั้งถัดไป

| ระดับ | ทำอะไร | ประเภท | แต้ม |
|---|---|---|---|
| 1 เดา (Predict) | อ่านโค้ด ติ๊กคำตอบที่เดาไว้ก่อน แล้วรันดูว่าตรงไหม | โจทย์หลัก (มีเฉลยในคาบ) | ข้อละ 1 |
| 2 แก้ (Tweak) | แก้ตัวเลขในส่วน `# ---- 1) ตั้งค่า (แก้ได้) ----` แล้วดูผล | โจทย์หลัก (มีเฉลยในคาบ) | ข้อละ 2 |
| 3 เติม (Fill-in) | เติมช่อง `____` ในไฟล์ฝึก ให้ผ่านการตรวจอัตโนมัติ | กิจกรรม 2 = โจทย์หลัก (มีเฉลยในคาบ) · กิจกรรม 1 = โจทย์เพิ่ม (โบนัส เฉลยคาบหน้า) | ลงมือทำและจดบันทึก 3 + ผ่านการตรวจ 1 |
| 4 สร้าง (Make) | เพิ่มความสามารถใหม่ 1 อย่างที่ยังไม่มีในไฟล์ตัวอย่างใดของคอร์ส | โจทย์เพิ่ม (โบนัส เฉลยคาบหน้า) | 5 |

> แต้ม Code Quest เป็นแต้มสนุก ไม่นับเกรด · เปิดคำใบ้ท้ายใบงาน 1 ขั้น = −1 แต้ม
> **ระดับ 3 ให้แต้มจากการลงมือ ไม่ใช่จากการทำสำเร็จ:** เขียนคำตอบที่เดาก่อนรัน · ลองอะไรไปบ้าง · ติดตรงไหน — ยังไม่ผ่านก็ได้ 3 แต้ม
> Code Quest ของกิจกรรม 4 (Edge AI) และเฉลยของมัน อยู่ในข้อ 6 ทั้งหมด

### ติดขัด? บันไดช่วยเหลือ 5 ขั้น

1. **คำใบ้ 3 ขั้น** ท้ายใบงาน (หัวข้อ "คำใบ้ Code Quest"): ขั้น 1 = แนวคิด · ขั้น 2 = โค้ดครึ่งหนึ่ง · ขั้น 3 = เกือบครบ (ระดับ 3 โจทย์หลัก ขั้น 3 = เฉลย) — เปิดทีละขั้น ขั้นละ −1 แต้ม
2. **อ่านข้อความ error** ด้วยตารางด้านล่าง
3. **ถามเพื่อน 3 คนก่อนถามผู้สอน** (ในทีมหรือทีมข้าง ๆ)
4. **ทางออกฉุกเฉิน:** รันไฟล์ตัวอย่างเต็ม (`s3/sf3_02_coop_ears.py` หรือ `s3/sf3_01_pen_guard.py`) เพื่อไปต่อก่อน แล้วค่อยเปิดดูว่าต่างจากของเราตรงไหน
5. **เฉลย:** โจทย์หลักอยู่ใน `s3/practise/solutions/` ตั้งแต่ในคาบ · ทุกข้อ (รวมโจทย์เพิ่ม) อธิบายทีละบรรทัดภายหลัง

| เห็นใน Console | แปลว่า | ทำอย่างไร |
|---|---|---|
| `NameError: name '____' isn't defined` | ยังมีช่อง `____` ที่ไม่ได้เติม | ค้นคำว่า `____` ในไฟล์ เติมให้ครบ |
| `NameError: name 'xxx' isn't defined` | สะกดชื่อผิด หรือใช้ชื่อที่ฟังก์ชันนั้นไม่รู้จัก | เทียบตัวสะกดกับชื่อในวงเล็บของฟังก์ชัน และชื่อในส่วน 1 ตั้งค่า |
| `SyntaxError` หรือ `IndentationError` | เขียนผิดรูปแบบภาษา | ดูเลขบรรทัดที่ Console บอก: ขาด `:` · วงเล็บไม่ครบ · ย่อหน้าไม่ตรงกับบรรทัดข้าง ๆ |
| `ยังไม่ถูก: ...` | เติมครบแล้ว แต่กฎยังให้คำตอบผิดในกรณีนั้น | อ่านตัวเลขของกรณีที่ผิด แล้วคิดใหม่ทีละช่อง |
| `MemoryError` | ไฟล์ยาวเกินหน่วยความจำของบอร์ด | กด **RESET** แล้วรันใหม่ · ถ้ายังเป็น ให้ตัดของที่เพิ่งเพิ่มออกบางส่วน |
