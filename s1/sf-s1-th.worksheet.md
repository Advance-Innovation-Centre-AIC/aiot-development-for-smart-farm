## 4. กิจกรรม 1 — โรงเรือนของเราตอนนี้ (`sf1_01_greenhouse_hello.py`)

- [ ] รันไฟล์ จอขึ้นการ์ด 3 ใบ: อุณหภูมิ (หน้าปัดมีเข็ม) ความชื้น (วงแหวน) ความกดอากาศ และกราฟย้อนหลังด้านล่าง (เส้นฟ้า = ความชื้น, เส้นส้ม = อุณหภูมิ)

**ขั้นแรก: ชดเชยค่าเซนเซอร์ (calibration)** — ชิปบนบอร์ดอุ่นตัวเอง เซนเซอร์ SHT40 จึงอ่านได้ **สูงกว่าอุณหภูมิห้อง** (บอร์ดจริงอ่านได้ราว 35-36 C ในห้องแอร์ที่ปกติ ~25-28 C ค่าชดเชยจึงมักอยู่ราว −9 ถึง −10) ถ้าไม่ชดเชย ทุกไฟล์จะบอกว่า "ร้อนไป" ตลอด

- [ ] ดูเลข **"ดิบ"** ในการ์ดอุณหภูมิ แล้วเทียบกับ **เทอร์โมมิเตอร์ในห้อง หรืออุณหภูมิที่ผู้สอนประกาศ** (ห้ามใช้แอปพยากรณ์อากาศ เพราะนั่นคืออุณหภูมินอกอาคาร)
- [ ] คำนวณ `TEMP_OFFSET = อุณหภูมิห้อง - ค่าดิบ` (ได้ค่าติดลบ) แก้บรรทัด `TEMP_OFFSET = 0.0` ในส่วน 1) แล้วรันใหม่
- [ ] สังเกต: ค่า "ดิบ" ไม่เปลี่ยน แต่เข็ม เลขใหญ่ และสีเปลี่ยน · ความชื้นก็ถูกแปลงเป็นของห้องให้เอง (อากาศรอบเซนเซอร์อุ่นกว่าห้อง ความชื้นสัมพัทธ์จึงอ่านได้ต่ำกว่าห้อง) ถ้าเทียบไฮโกรมิเตอร์ในห้องแล้วค่าที่แปลงสูงเกินจริง ให้ตั้ง `HUM_FIX = False` · จดค่านี้ไว้ **ใช้ต่อในกิจกรรม 2 และภารกิจกลุ่ม**

| ค่าดิบบนบอร์ด (C) | อุณหภูมิห้องจริง (C) | วัดจาก | TEMP_OFFSET ที่ใส่ |
|---|---|---|---|
| | | ☐ เทอร์โมมิเตอร์ในห้อง ☐ ผู้สอนประกาศ | |

- [ ] ดูจอไฟ RGB บนฐานบอร์ด: โชว์อุณหภูมิ (ที่ชดเชยแล้ว) เป็นเลขตัวใหญ่ (เขียว = ปกติ, เหลือง = เกิน 30, แดง = เกิน 35)

## 6. กิจกรรม 3 — รดน้ำอัตโนมัติ (`sf1_03_auto_irrigation.py`)

ลูกบิด **VR1** = เซนเซอร์ความชื้นดิน (จำลอง) · **VR2** = เกณฑ์เปิดปั๊ม · **VR3** = น้ำในถัง · ไฟสีฟ้าบนบอร์ด = ปั๊มน้ำ
จอไฟ RGB: ซ้าย = ความชื้นดิน (เส้นแดง = เกณฑ์) · กลางสีเขียว = น้ำกำลังไหล · ขวา = น้ำในถัง
บนจอ: ไฟปั๊ม + วงหมุนตอนปั๊มเดิน · **สวิตช์บนจอ** = อัตโนมัติ / มือ · กราฟ: ฟ้า = ความชื้นดิน, แดง = เกณฑ์เปิด, เขียว = เกณฑ์ปิด
**SW5 (ปุ่มล่าง)** กดค้าง = รดน้ำเอง · **SW6 (ปุ่มบน)** = ล้างตัวนับ

> **ในงานจริง** — ลองนึกภาพฟาร์มของจริง:
> **VR1** = โหนดเซนเซอร์ความชื้นดินไร้สาย ปักในแปลง ส่งค่ามาทาง MQTT · **VR3** = เซนเซอร์ระดับน้ำในถังไร้สาย
> **ไฟสีฟ้า "ปั๊ม"** = PLC / รีเลย์ต่อ Wi-Fi ที่รับคำสั่งเปิดปั๊มทาง MQTT แล้วขับปั๊มจริง
> **Dev Kit ของเรา** = Smart HMI ที่คิดและสั่งงาน — **คาบ 2 เราจะต่อของพวกนี้ผ่าน MQTT จริง**

- [ ] หมุน VR3 ให้ถังเต็มก่อน แล้วหมุน VR1 ลงช้า ๆ บันทึกค่าที่ปั๊ม **เปิด** และหมุนขึ้นบันทึกค่าที่ปั๊ม **ปิด**
- [ ] **การทดลอง:** หมุน VR1 ค้างไว้ตรงขอบเกณฑ์ แล้วขยับเบา ๆ 30 วินาที นับครั้งที่ปั๊มเปิด
