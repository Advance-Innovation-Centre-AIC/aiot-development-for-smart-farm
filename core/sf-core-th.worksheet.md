## 1. สิ่งที่จะทำได้เมื่อจบคาบ

- **LO1 (วัด)** แยกข้อมูลทุกตัวบนบอร์ดตาม **รูปร่างของข้อมูล** (เหตุการณ์ / ระดับ / ค่าเดี่ยว / เวกเตอร์ / สตรีม) แล้วเลือกจังหวะอ่าน การกรองปุ่ม การแปลงหน่วย และการสอบเทียบได้
- **LO2 (ตัดสิน)** เลือกตัวกรองตาม **รูปของสัญญาณรบกวน** (สั่นเล็ก ๆ → EMA · กระตุก → Median · ลอยช้า ๆ → เส้นฐาน) และคำนวณค่าเฉลี่ย ส่วนเบี่ยงเบนมาตรฐาน และ z-score แบบหน้าต่างเลื่อนได้
- **LO3 (ตัดสิน)** ไต่ **บันไดการตัดสินใจ** (เกณฑ์ → hysteresis → ต้องค้างนาน → state machine → สถิติ → AI ที่มีประตูความมั่นใจ) และบอกเหตุผลได้ว่าทำไมขั้นที่ต่ำที่สุดที่ได้ผลจึงดีที่สุด
- **LO4 (ทำ)** ออกแบบ **ภาษาสถานะ** เดียว (สี + รูปแบบ + เสียง) · รายงาน **เมื่อเปลี่ยน + ส่งว่ายังอยู่** · อธิบายได้ว่าทำไมคำสั่งต้องมีคำยืนยัน ระบบกันพลาด และทางถอยที่ปลอดภัย
- **LO5 (ทำ)** อธิบาย **MQTT · MQTTS · Modbus TCP** (บทบาท พอร์ต หน้าตาเฟรม) และบอกได้ตรง ๆ ว่าบอร์ดรุ่นนี้ทำอะไรได้และยังทำอะไรไม่ได้
- **LO6 (โชว์)** เลือก widget ตามชนิดข้อมูล ปรับหน้าตาขณะรัน และ **ส่งต่อเหตุการณ์** จากจอไปอ่านค่าตั้งและสั่งงาน
- **LO7 (ทั้งหมด)** กรอก **การ์ดออกแบบ วัด–ตัดสิน–ทำ–โชว์** หนึ่งหน้าให้โปรเจกต์ของกลุ่ม

## Code Quest — อ่าน · เดา · แก้ · เติม · สร้าง

ทุกส่วนมีโจทย์เป็นขั้น ทำเรียงจากระดับ 1 ขึ้นไป ทำได้ถึงไหนก็ได้แค่นั้น
**โจทย์หลัก (มีเฉลยในคาบ)** = ทุกกลุ่มควรทำให้ได้ มีเฉลยให้เปิดดูได้ในคาบ ไม่มีใครติดค้าง
**โจทย์เพิ่ม (โบนัส เฉลยคาบหน้า)** = ทำเพื่อสนุกและเก็บแต้ม ไม่มีผลต่อเกณฑ์ผ่านคาบ

| ระดับ | ทำอะไร | ประเภท | แต้ม |
|---|---|---|---|
| 1 เดา (Predict) | อ่านโค้ด เขียนคำตอบที่เดาไว้ก่อน แล้วรันดูว่าตรงไหม | โจทย์หลัก (มีเฉลยในคาบ) | ข้อละ 1 |
| 2 แก้ (Tweak) | แก้ตัวเลขในส่วน `# ---- 1) ตั้งค่า ----` แล้วดูผล | โจทย์หลัก (มีเฉลยในคาบ) | ข้อละ 2 |
| 3 เติม (Fill-in) | เติมช่อง `____` ในไฟล์ฝึก ให้ผ่านการตรวจอัตโนมัติ | ส่วนที่ 2 และ 3 = โจทย์หลัก (มีเฉลยในคาบ) · ส่วนที่ 1 และ 4 = โจทย์เพิ่ม (โบนัส เฉลยคาบหน้า) | ลงมือทำและจดบันทึก 3 + ผ่านการตรวจ 1 |
| 4 สร้าง (Make) | เพิ่มความสามารถใหม่ 1 อย่าง | โจทย์เพิ่ม (โบนัส เฉลยคาบหน้า) | 5 |

> แต้ม Code Quest เป็นแต้มสนุก ไม่นับเกรด · เปิดคำใบ้ท้ายใบงาน 1 ขั้น = −1 แต้ม
> ไฟล์ฝึกอยู่ใน `core/practise/` · เฉลยโจทย์หลักอยู่ใน `core/practise/solutions/`
> ไฟล์ฝึกตรวจคำตอบที่ส่วน **3) สมอง** ก่อนเปิดจอ ผ่านครบ = Console ขึ้น "ผ่าน!" แล้วเล่นต่อได้เหมือนไฟล์ตัวอย่าง

### ติดขัด? บันไดช่วยเหลือ 5 ขั้น

1. **คำใบ้ 3 ขั้น** ท้ายใบงาน (หัวข้อ "คำใบ้ Code Quest"): ขั้น 1 = แนวคิด · ขั้น 2 = โค้ดครึ่งหนึ่ง · ขั้น 3 = เกือบครบ — เปิดทีละขั้น ขั้นละ −1 แต้ม
2. **อ่านข้อความ error** ด้วยตารางด้านล่าง
3. **ถามเพื่อน 3 คนก่อนถามผู้สอน** (ในทีมหรือทีมข้าง ๆ)
4. **ทางออกฉุกเฉิน:** รันไฟล์ตัวอย่างเต็มในโฟลเดอร์ `core/` เพื่อไปต่อก่อน แล้วค่อยเปิดดูว่าต่างจากของเราตรงไหน
5. **เฉลย:** โจทย์หลักอยู่ใน `core/practise/solutions/` ตั้งแต่ในคาบ · โจทย์เพิ่มอธิบายในการพบกันครั้งถัดไป

| เห็นใน Console | แปลว่า | ทำอย่างไร |
|---|---|---|
| `NameError: name '____' isn't defined` | ยังมีช่อง `____` ที่ไม่ได้เติม | ค้นคำว่า `____` ในไฟล์ เติมให้ครบ |
| `NameError: name 'xxx' isn't defined` | สะกดชื่อผิด หรือใช้ชื่อที่ฟังก์ชันนั้นไม่รู้จัก | เทียบตัวสะกดกับบรรทัดด้านบนของฟังก์ชัน |
| `SyntaxError` หรือ `IndentationError` | เขียนผิดรูปแบบภาษา | ดูเลขบรรทัดที่ Console บอก: ขาด `:` · วงเล็บไม่ครบ · ย่อหน้าไม่ตรง |
| `TypeError: can't convert float to int` | ส่งเลขทศนิยมให้ widget ที่รับแต่จำนวนเต็ม | ห่อด้วย `int(round(x))` ก่อนส่งให้ `.value()` หรือ `.set_next()` |
| `TypeError: extra positional arguments given` | เรียกตัวกรอง `dsp` แบบไม่ใส่ชื่ออาร์กิวเมนต์ | เขียน `dsp.EMA(alpha=0.2)` ไม่ใช่ `dsp.EMA(0.2)` |
| `ยังไม่ถูก: ...` | เติมครบแล้ว แต่ยังให้คำตอบผิดในกรณีนั้น | อ่านกรณีที่ผิด แล้วคิดใหม่ทีละช่อง |
| `MemoryError` | ไฟล์ยาวเกินหน่วยความจำของบอร์ด | กด **RESET** แล้วรันใหม่ · ถ้ายังเป็น ตัดของที่เพิ่งเพิ่มออกบางส่วน · คำอธิบายใช้ `#` ไม่ใช้ docstring |
| `OSError` จากบรรทัด `rgbmatrix` | จอไฟ RGB ตอบไม่ทัน | ห่อด้วย `try: ... except OSError: pass` |

### หน้า 1 — วัด (Sense)

**กฎทอง:** (1) อ่านให้ถูกจังหวะ: ปุ่มทุก 10–20 ms · อากาศทุก 1 วินาที · จอทุก 0.5 วินาที (2) แปลงให้มีหน่วยทันทีที่อ่าน (3) สอบเทียบก่อนเชื่อ: ค่าชดเชย (offset) · ตั้งศูนย์ (tare) · สองจุด (gain)

| คำสั่ง | ได้อะไร |
|---|---|
| `buttons.pressed(i)` | `True` = กดอยู่ · `i` 0 = SW6 (ปุ่มบน) · 1 = SW5 (ปุ่มล่าง) · กรองสั่น 50 ms ตอนที่เราเรียก |
| `pots.read(i)` · `pots.read_all()` · `pots.norm(i)` | 0–4095 ของ VR1–VR4 (`i` 0–3) · ทั้ง 4 ตัวเป็น tuple · 0.0–1.0 |
| `sensors.sht40.temperature()` · `.humidity()` · `.temperature_humidity()` | °C · %RH · (°C, %RH) — อ่านสูงกว่าห้องเพราะบอร์ดอุ่น จึงมี `TEMP_OFFSET` |
| `sensors.dps368.pressure()` | hPa |
| `sensors.bmi270.acceleration()` · `.motion()` | (ax, ay, az) m/s² · (ax, ay, az, gx, gy, gz) |
| `dsp.tilt(ax, ay, az)` | (roll, pitch) องศา |
| `mic.start(samples=256)` · `mic.level()` · `mic.raw()` · `mic.stop()` | เริ่มฟัง 16 kHz · ความดัง 0–100 · บัฟเฟอร์ตัวอย่างเสียงล่าสุด · หยุด |
| `time.ticks_ms()` · `time.ticks_diff(a, b)` · `time.ticks_add(t, ms)` | นาฬิกา ms · ผลต่าง (ใช้แทน a − b เสมอ) · เวลาในอนาคต |

```python
t_btn = t_air = t_scr = time.ticks_ms()
while True:
    now = time.ticks_ms()
    if time.ticks_diff(now, t_btn) >= 20:      # ปุ่ม: ถี่
        t_btn = now
        down = buttons.pressed(1)              # SW5 (ปุ่มล่าง)
    if time.ticks_diff(now, t_air) >= 1000:    # อากาศ: ช้า
        t_air = now
        t = read_temp() + TEMP_OFFSET
    if time.ticks_diff(now, t_scr) >= 500:     # จอ: 2 ครั้งต่อวินาที
        t_scr = now
        show(w, t, down)
    time.sleep_ms(5)
```

|---|---|
| `dsp.EMA(alpha=0.2)` · `dsp.SMA(window=8)` · `dsp.Median(window=5)` · `dsp.Kalman1D(q=0.01, r=1.0)` · `dsp.LPF(cutoff=…, fs=…)` · `dsp.HPF(cutoff=…, fs=…)` | ตัวกรอง — **ต้องใส่ชื่ออาร์กิวเมนต์** · SMA 2–64 · Median 3–15 เลขคี่ |
| `f.update(x)` · `f.value()` · `f.reset()` | ป้อนค่าใหม่แล้วได้ค่าที่กรองแล้ว (ทศนิยม) · ค่าล่าสุด · ล้าง |
| `dsp.fft_mag(samples, 256)` | ขนาดของแต่ละความถี่ 128 ช่อง · ช่องละ 16,000 ÷ 256 = 62.5 Hz · N ต้องเป็นกำลังของ 2 ตั้งแต่ 8 ถึง 512 |
| `dsp.dew_point(t, rh)` · `dsp.heat_index(t, rh)` · `dsp.comfort_zone(t, rh)` | จุดน้ำค้าง °C · ดัชนีความร้อน · ระดับความสบาย |
| `edge_ai.models()` · `edge_ai.select(index)` · `edge_ai.start()` · `edge_ai.result()` · `edge_ai.stop()` | รายการโมเดล (dict) · เลือกด้วยเลข `index` ของแถว · เริ่ม · ผลล่าสุด dict มี `label` `conf` `scores` `seq` (หรือ `None`) · หยุด |

```python
buf = []                                # หน้าต่างเลื่อน 30 ค่า (ใช้ list ธรรมดา)
def add(x):
    buf.append(x)
    if len(buf) > 30:
        buf.pop(0)
    m = sum(buf) / len(buf)
    sd = math.sqrt(sum((v - m) ** 2 for v in buf) / len(buf))
    z = (x - m) / sd if sd > 0 else 0
    return m, sd, z                     # |z| > 2.5 = ผิดปกติ
ema = dsp.EMA(alpha=0.2)
chart.set_next(0, int(round(ema.update(x))))   # widget รับจำนวนเต็ม
```

| `TypeError: extra positional arguments given` | ใส่ชื่ออาร์กิวเมนต์: `dsp.EMA(alpha=0.2)` |
| `TypeError: can't convert float to int` | `int(round(x))` ก่อนส่งให้ `.value()` / `.set_next()` |
| `ValueError` จาก `fft_mag` | N ต้องเป็น 8, 16, 32 … 512 |
| AI นับผลเดิมซ้ำ | `result()` คืนผลล่าสุดทุกครั้งที่ถาม — นับเฉพาะเมื่อ `seq` เปลี่ยน |

**บอร์ดยังทำไม่ได้:** `dsp` ไม่มี mean / std / z-score (เขียนเอง) · `collections.deque` บนบอร์ดวนลูปอ่านไม่ได้ (ใช้ list) · `edge_ai.select()` รับเลข ไม่รับชื่อ

### หน้า 3 — ทำ (Act & Report)

**กฎทอง:** (1) สถานะหนึ่ง ภาษาเดียว: สี + รูปแบบ + เสียงเดียวกันทุกที่ (2) ส่งเมื่อเปลี่ยน + ส่งว่ายังอยู่ (heartbeat) (3) ทุกคำสั่งต้องมีคำยืนยัน หมดเวลาแล้วถอยไปทางปลอดภัย (ปิดปั๊ม)

```python
def beep(n=76, ms=120):
    ui.tone(n, ui.WAVE_SINE, VOLUME, ms)      # ok 72→79 · alert 84→76 · press 76 · done 79→84

def should_send(v, last_sent, t_last, now):
    if last_sent is None:
        return "first"
    if abs(v - last_sent) > DEADBAND:
        return "change"
    if time.ticks_diff(now, t_last) >= HEARTBEAT_S * 1000:
        return "heartbeat"
    return None
```

### หน้า 4 — โชว์ (จอบอร์ด)

**กฎทอง:** (1) สร้าง widget ครั้งเดียว แล้วอัปเดตเฉพาะที่เปลี่ยน (2) ฟังเหตุการณ์ทุกรอบ: `ui.poll()` ทุก 20–50 ms อ่านจนหมด (3) คำสั่งอันตรายต้องยืนยัน (กดค้าง หรือ MsgBox)

routes = {(b_on.id(), "long_pressed"): pump_on,     # กดค้าง = เปิดปั๊ม

    while evs:                                      # อ่านจนหมด ไม่ให้คิวล้น
