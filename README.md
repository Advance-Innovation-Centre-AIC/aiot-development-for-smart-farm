# AIoT Development for Smart Farm

### Intensive Course · TESAIoT Dev Kit · MicroPython

เปลี่ยนบอร์ดเล็ก ๆ หนึ่งตัวให้เป็น **Smart IoT Gateway** ของฟาร์ม: อ่านอากาศในโรงเรือน ดูแลความชื้นดิน เฝ้าแท็งก์น้ำ ส่งเสียงเตือนเมื่อพืชเริ่มเครียด แล้วส่งข้อมูลขึ้นอินเทอร์เน็ตให้แอปบนมือถือของคุณเองแสดงผลและแจ้งเตือนแบบเรียลไทม์

หลักสูตรนี้เน้นลงมือทำตั้งแต่นาทีแรก ทุกตัวอย่างเป็นโจทย์ฟาร์มจริง เห็นผลทันทีบนหน้าจอสัมผัส จอไฟ RGB และลำโพงของบอร์ด แล้วต่อยอดเป็นโปรเจกต์ของทีมเอง

---

## สิ่งที่คุณจะได้สร้าง

- **Smart HMI** หน้าจอควบคุมฟาร์มสวย ๆ ด้วยหน้าปัด กราฟเส้น แท็บ ไฟสถานะ และตารางบันทึกเหตุการณ์
- **ระบบรดน้ำอัตโนมัติ** ที่ตัดสินใจเองอย่างมีเหตุผล (hysteresis) และปกป้องปั๊มเมื่อน้ำในถังเหลือน้อย
- **ไฟสถานะที่มองเห็นจากอีกฝั่งห้อง** บนจอไฟ RGB 16x8 จุด พร้อมเสียงเตือนจากลำโพง
- **ฟาร์มที่ต่ออินเทอร์เน็ต** ผ่าน MQTT broker สาธารณะ (HiveMQ, Mosquitto) ส่งค่าและรับคำสั่งจากที่ไหนก็ได้
- **แอปของคุณเอง** เว็บแดชบอร์ดหรือแอปมือถือที่ดึงข้อมูลจาก broker มาแสดงกราฟและแจ้งเตือน จะเขียนเองหรือ vibe coding ก็ได้
- **AI ในฟาร์ม** เรดาร์เฝ้าคอก ไมโครโฟนฟังเล้า และตรวจการสั่นผิดปกติของปั๊ม

## ภาพใหญ่: บอร์ดคือ Smart IoT Gateway

```
เซนเซอร์ไร้สายในไร่ (ดิน ถังน้ำ อากาศ) ──MQTT/Wi-Fi──┐
เซนเซอร์บนบอร์ด (อุณหภูมิ ความชื้น IMU เรดาร์ ไมค์)  ───┤
                                              ▼
                 TESAIoT Dev Kit = Smart IoT Gateway
          ตัดสินใจ · หน้าจอ Smart HMI · จอไฟ RGB · เสียงเตือน
                     │ MQTT (broker สาธารณะ เช่น HiveMQ, Mosquitto)
          ┌──────────┴───────────┐
          ▼                      ▼
 PLC / รีเลย์ Wi-Fi → ปั๊ม วาล์ว    เว็บแอป / แอปมือถือของคุณเอง
                                  (กราฟสวย ๆ + แจ้งเตือนเข้ามือถือ)
```

## โปรเจกต์ของทีม: 5 เสาหลัก

| เสา | สิ่งที่ใช้ |
|---|---|
| 1. Smart HMI | หน้าจอสัมผัส (`ui`) + จอไฟ RGB 16x8 (`rgbmatrix`) |
| 2. เซนเซอร์ | อุณหภูมิ/ความชื้น SHT40 · ความกดอากาศ DPS368 · IMU BMI270 · เรดาร์ · ไมโครโฟน |
| 3. ปุ่มตั้งค่า | ลูกบิด VR1–VR4 (`pots`) + ปุ่ม SW5 (ล่าง) / SW6 (บน) (`buttons`) |
| 4. เสียง | ลำโพง `ui.sfx(...)` และ `ui.tone(...)` |
| 5. MQTT + แอปของตัวเอง | บอร์ดส่งค่า/รับคำสั่งผ่าน broker แล้วสร้างแอปเว็บหรือมือถือมาแสดงผลและแจ้งเตือน |

## เริ่มต้นใช้งาน

1. ติดตั้ง **TESAIoT PSE84 Programmer** จาก [GitHub Releases](https://github.com/wiroon/TESAIoT_PSE84_Programmer/releases)
2. เสียบบอร์ดด้วยสาย USB-C เข้าพอร์ต KitProg3
3. เปิด **BENTO IDE** ที่ <https://ide.tesaiot.com/> ด้วย Chrome หรือ Edge → หน้า Welcome → **Remote Flash** → เลือก **BENTO Firmware — TESAIoT Dev Kit** แล้วกด **Flash this board →** (รุ่น v2.4.1)
4. เปิดไฟล์ตัวอย่าง แล้วกด **Program to Device**
5. ไม่มีบอร์ดอยู่ใกล้มือ? ทุกตัวอย่างลองเล่นได้ใน **BENTO Emulator** ภายใน BENTO IDE
