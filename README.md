# AIoT Development for Smart Farm — Short Course 3 คาบ (อิงหลักสูตรแม่ AIoT in Action 12 คาบ)

**ผู้เรียน:** นิสิตชั้นปีที่ 3 คณะโลจิสติกส์ แขนงวิชา Smart Farming (มีพื้นฐาน Python) · ห้อง 109 อาคารเก่า
**รูปแบบ:** 20 กลุ่ม × 2 คน · บอร์ด **TESAIoT Dev Kit** กลุ่มละ 1 ตัว · **firmware 2.4.1** (Remote Flash จากหน้า Welcome ของ BENTO IDE) · เรียนต่อนอกเวลาด้วย **BENTO Emulator**
**แนวคิด:** เล่นของจริงให้เห็นภาพก่อน แล้วค่อยถามว่าทำงานยังไง · ทุกตัวอย่างเป็นโจทย์ฟาร์ม · ทุกคาบจบด้วยชิ้นงานที่ต่อยอดเป็นโปรเจกต์กลุ่ม

## ภาพใหญ่: บอร์ดของเราคือ Smart IoT Gateway

```
เซนเซอร์ไร้สายในไร่ (ดิน ถังน้ำ อากาศ) ──MQTT/Wi-Fi──┐
เซนเซอร์บนบอร์ด (อุณหภูมิ ความชื้น IMU เรดาร์ ไมค์) ───┤
                                                  ▼
                 TESAIoT Dev Kit = Smart IoT Gateway
          ตัดสินใจ · หน้าจอ Smart HMI · จอไฟ RGB · เสียงเตือน
                     │ MQTT (broker สาธารณะ เช่น HiveMQ, Mosquitto)
          ┌──────────┴───────────┐
          ▼                      ▼
 PLC / รีเลย์ Wi-Fi → ปั๊ม วาล์ว    เว็บแอป / แอปมือถือของนิสิตเอง
                                  (กราฟสวย ๆ + แจ้งเตือนเข้ามือถือ)
```

นิสิตไม่ต้องทำทุกอย่างบนบอร์ด บอร์ดเป็นเกตเวย์ที่รวมข้อมูลและสั่งงาน ส่วนการแสดงผลและแจ้งเตือนสวย ๆ ทำเป็นแอปของกลุ่มเองได้ (เขียนเองหรือ vibe coding ก็ได้) โดยเริ่มจากชุดตัวอย่างใน `apps/`

## โปรเจกต์ของแต่ละกลุ่ม: อุปกรณ์ฟาร์มอัจฉริยะ 5 เสาหลัก

| เสา | บนบอร์ด / บนเครื่องนิสิต | เรียนในคาบ |
|---|---|---|
| 1. Smart HMI | หน้าจอสัมผัสของบอร์ดที่ออกแบบเอง (`ui`) + จอไฟ RGB 16x8 (`rgbmatrix`) | 1, 3 |
| 2. เซนเซอร์ | อุณหภูมิ/ความชื้น SHT40 · ความกดอากาศ DPS368 · IMU BMI270 · เรดาร์ · ไมค์ | 1, 3 |
| 3. ปุ่มตั้งค่า | ลูกบิด VR1-VR4 (`pots`) + ปุ่ม SW4/SW5 (`buttons`) ใช้ตั้งเกณฑ์ สลับโหมด จำลองเซนเซอร์ | 1 |
| 4. เสียง | ลำโพง `ui.sfx(...)` เสียงสำเร็จรูป 21 แบบ และ `ui.tone(...)` แต่งเสียงเอง | 1 |
| 5. MQTT + แอปของตัวเอง | บอร์ดส่งค่า/รับคำสั่งผ่าน broker สาธารณะ แล้วนิสิตเขียนแอปบนโน้ตบุ๊ก (Python หรือหน้าเว็บ) มา subscribe เอง | 2, 3 |
