เปิดโหมดนี้บนโน้ตบุ๊กเมื่อใช้ทางเลือกที่ 1: บอร์ด Gateway 1 ตัว + โน้ตบุ๊ก 1 เครื่อง หน้านี้เล่นเป็นแปลงผักและ PLC ให้เอง ไม่ต้องติดตั้งอะไรเพิ่ม

PLC จำลองรับคำสั่งจาก Gateway ทาง .../plc/cmd ถ้าบอร์ดรัน sf2_03_remote_pump.py (ภารกิจกลุ่ม) ไม่ต้องเปิด PLC จำลอง ปั๊มคือไฟสีฟ้าบนบอร์ด และสถานะดูได้จากการ์ด "ปั๊ม" ด้านบน

กดเริ่มทุกครั้งแปลงกลับไปที่ดิน 45 % ถัง 80 % · เลื่อนดินลงต่ำกว่า 30 % เพื่อให้ Gateway สั่งรดน้ำเอง · เลื่อนถังลงต่ำกว่า 10 % เพื่อดู PLC ไม่ยอมเปิดปั๊ม

คำสั่งจาก Gateway ใช้ topic .../plc/cmd ตามสัญญาข้อ 4.2 เช่น {"pump":1,"sec":10} และ Simulator รายงาน plc/state + field/soil + field/tank ตามสัญญาข้อ 3.5–3.6
