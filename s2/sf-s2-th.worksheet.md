## 4. รู้จักเส้นทางข้อมูลของกลุ่ม

ในคาบนี้ใช้ MQTT เป็นตัวกลาง ข้อมูลของแต่ละกลุ่มแยกด้วยชื่อ `TEAM`

ตัวอย่าง ถ้ากลุ่มคือ `team05`

  MQTT topic                      ใช้ทำอะไร
  ------------------------------- ----------------------
  `bento-aiot/team05/telemetry`   ค่าที่บอร์ดส่งออก
  `bento-aiot/team05/event`       เหตุการณ์ที่เกิดขึ้น
  `bento-aiot/team05/cmd`         คำสั่งจากแอปกลับไปที่บอร์ด

### ข้อมูลจาก `sf2_02_greenhouse_report.py`

จำไว้ว่า `soil`, `light` และ `tank` ในกิจกรรมนี้เป็น **ค่าจำลองจากลูกบิด**
ไม่ใช่ค่าจากเซนเซอร์ดิน/แสง/ระดับน้ำจริง

### ข้อมูลจาก `sf2_03_remote_pump.py`

ตัวอย่าง:

``` json
{"id":"team05","n":7,"soil":20,"tank":80,"pump":1,"sim":"soil tank"}
```

-   `pump = 1` หมายถึงปั๊มกำลังเปิด
-   `pump = 0` หมายถึงปั๊มปิด

### ทดลองคำสั่ง

  คำสั่ง                                 ผลที่คาดว่าจะเกิด                               ผลที่เกิดจริง
  ------------------------------------ ------------------------------------------- -----------
  `{"cmd":"pump","on":1,"sec":10}`     ปั๊มเปิด 10 วินาที                               
  `{"cmd":"pump","on":1,"sec":9999}`   บอร์ดจำกัดเวลาไว้ไม่เกิน 30 วินาที                 
  `{"cmd":"pump","on":0}`              ปั๊มหยุดทันที                                    
  `{"cmd":"say","text":"HELLO"}`       ข้อความ HELLO วิ่งบนจอ LED                     
  `{"cmd":"ack"}`                      ใช้รับทราบแจ้งเตือนจาก `sf2_04_crop_alert.py`   

### ทดสอบการป้องกัน

  การทดลอง               ผลที่เกิด   เพราะอะไร
  ---------------------- -------- -----------
  ถัง \< 10% แล้วสั่งเปิดปั๊ม            
  สั่ง 9999 วินาที                    
  กด SW5 ขณะปั๊มทำงาน

## 11. ต่อยอด --- Smart IoT Gateway

ส่วนนี้ใช้สำหรับกลุ่มที่ทำงานหลักเสร็จแล้ว หรือใช้ต่อกับโปรเจกต์ของกลุ่ม

แนวคิดของระบบจริงคือ:

**โหนดเซนเซอร์ส่งข้อมูลขึ้น MQTT → Gateway อ่านข้อมูลและตัดสินใจ → Gateway ส่งคำสั่งไป
PLC → PLC คุมปั๊ม**

-   [ ] รัน
    [`sf2_06_smart_gateway.py`](https://github.com/Advance-Innovation-Centre-AIC/aiot-development-for-smart-farm/blob/main/s2/sf2_06_smart_gateway.py)

    [`farm_web.html`](https://advance-innovation-centre-aic.github.io/aiot-development-for-smart-farm/s2/app/farm_web.html?team=team__)
    (กด **เริ่ม PLC Simulator**) หรือใช้บอร์ดอีกกลุ่มเป็น field station
-   [ ] ใช้ TEAM เดียวกัน
-   [ ] ดูว่าดินต่ำกว่า 30% แล้ว Gateway สั่งรดน้ำเอง
-   [ ] กด **จำลอง PLC หลุด** ใน `farm_web.html` แล้วดูว่า Gateway แจ้ง PLC หลุดหรือไม่

โครงสร้างนี้สำคัญกับงาน Smart Farm เพราะทำให้การตัดสินใจ การสั่งงาน
และการตรวจสอบสถานะของปั๊มแยกหน้าที่กันชัดเจน

## คีย์ข้อมูลที่ใช้บ่อย

  คีย์         ความหมาย
  ---------- ----------------------------------
  `temp_c`   อุณหภูมิ (°C)
  `rh`       ความชื้นอากาศ (%)
  `hpa`      ความกดอากาศ (hPa)
  `az`       ค่าการเอียงจาก BMI270
  `soil`     ความชื้นดินจำลองจาก VR1 (%)
  `light`    แสงจำลองจาก VR3 (%)
  `tank`     น้ำในถังจำลองจาก VR4 (%)
  `by`       ส่งเพราะครบเวลา (timer) หรือกด SW5
