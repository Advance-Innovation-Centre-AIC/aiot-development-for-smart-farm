Session 1 ใช้ลูกบิดบนบอร์ดแทนเซนเซอร์ไร้สาย และไฟสีฟ้าแทน PLC คุมปั๊ม · Session 2 ต่อจริงผ่าน MQTT

เตรียมบอร์ดครั้งแรก (ราว 20 นาที)

  1. ติดตั้ง TESAIoT PSE84 Programmer — หน้า Releases · macOS: …_universal.dmg · Windows: …_x64-setup.exe — เปิดค้างไว้ แล้วสลับเป็นโหมด Remote
  2. เสียบ USB-C เข้าพอร์ต KitProg3 ของบอร์ด (ใช้สายที่ส่งข้อมูลได้)
  3. เปิด Chrome หรือ Edge → ide.tesaiot.com → Welcome → TESAIoT Dev Kit → Flash this board → → จับคู่กับ Programmer → Flash v2.4.1
  4. จอบอร์ดขึ้น v2.4.1 → กด Connect ใน IDE
แก้ปัญหาเร็ว

เครื่องเตือนตอนเปิดแอป → เรียกผู้สอน · คอมไม่เห็นบอร์ด → เปลี่ยนสาย/พอร์ต USB · จอดำหลังแฟลชหรือรันโค้ด → กด RESET หนึ่งครั้ง ยังดำให้ถอดสายแล้วเสียบใหม่ · SW2 บนฐานบอร์ดคือสวิตช์ตัดไฟ ห้ามโยก

เรียนต่อที่บ้าน: BENTO Emulator

ทุกไฟล์ในคอร์สรันใน BENTO Emulator ได้ (ในเมนูของ BENTO IDE) ใช้แผง TESAIoT DEV KIT (ลูกบิด VR1–VR4 ปุ่มคู่ของฐานบอร์ด จอไฟ RGB) กับแผง ENVIRONMENT/TILT แทนบอร์ดจริง — ค่าเซนเซอร์ใน Emulator เป็นค่าจำลอง
