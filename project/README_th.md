## วิธีใช้

1. คัดลอกไฟล์ไอเดียเป็น `g<เลขทีม>_<ชื่อโปรเจกต์>.py` เช่น `g05_mango_box.py` (เก็บไฟล์เดิมไว้เทียบ)
2. แก้ `WIFI_SSID` `WIFI_PASS` `TEAM` ด้านบนไฟล์ (อย่าส่งไฟล์ที่ใส่รหัสจริงให้ใคร)
3. กด **Program to Device** (หรือรันใน BENTO Emulator ก่อน)
4. เปิดหน้าเว็บของไอเดีย: `project/idea_web.html?idea=N&team=teamXX` (N = เลขไอเดีย)
5. แก้ทีละ 1–2 จุดตาม "ทีมต้องแก้ 3 อย่าง" ในหัวไฟล์ แล้วรันดูผลทุกครั้ง

## ลองใน Emulator (ทำให้เกิดเหตุ)

| ไอเดีย | ทำแบบนี้ |
|---|---|
| 1 | เลื่อน VR3 ไปสุด (+10 C) จนขึ้น HOT แล้วกด SW5 = รับทราบ (บนบอร์ดจริง: เป่าลมหายใจหรือจับเซนเซอร์ก็ได้) |
| 2 | เลื่อน VR3 ไปสุดจนขึ้นร้อนเกิน แล้วกด SW5 = ลูกค้ารับของ จอขึ้น "ส่งถึงแล้ว" และจอไฟ DELIVERED |
| 3 | เลื่อนความชื้นในแผงเซนเซอร์ให้เกิน 70 % (เกิน 80 % = เสี่ยงรา) แล้วกด SW5 · VR3 อย่างเดียวไม่พอ เพราะไซโลเตือนที่ความชื้น |
| 4 | เลื่อน VR1 ต่ำกว่า 30 ขึ้น "แห้ง ควรรด" แล้วสั่งรดน้ำจากหน้าเว็บ · SW5 = หยุดรดฉุกเฉิน |
| 5 | ตั้ง VR3 = เขตเตือน แล้วเลื่อน VR1 (ระยะเป้า) ให้ใกล้กว่าเขตเตือน จนขึ้น INTRUDER · SW6 = รับทราบ · SW5 = เปิด/ปิดเฝ้า |
| 6 | เลื่อน VR4 ต่ำกว่า 10 แล้วสั่งเปิดปั๊มจากหน้าเว็บ: จอขึ้น "ไม่เปิด!" เสียงต่ำ และจอไฟ LOW |
| 7 | ไม่แตะ 5 วิแรก (เรียนรู้ปกติ) แล้วกด Shake ถี่ ๆ ต่อเนื่องราว 1 วิ จนขึ้น VIB · ระหว่างนั้นสั่งเปิดปั๊ม = ถูกปฏิเสธ |
| 8 | เลื่อน VR3 ไปสุดจนขึ้น HEAT หรือเลื่อนความชื้นในแผงเซนเซอร์เกิน 75 % แล้วกด SW5 |

## ข้อความ MQTT ที่เพิ่มจากสัญญา (หน้าเว็บต้องรู้)

หัวข้อและคีย์เดิมตาม `s2/app/MQTT_CONTRACT_th.md` ทุกตัว · ที่เพิ่ม:

- **ไอเดีย 1 2 3 8:** ค่า `crop` ใหม่ (`mango` `strawberry` `durian` · `veg` `fruit` `flower` · `paddy` `seed` `corn` · `layer` `broiler` `chick`)
- **ไอเดีย 2:** event `{"id":"team05","event":"delivered","by":"sw5","trip_min":7,"temp_c":27.4}` (`by` = `sw5` หรือ `app` · `temp_c` อาจเป็น `null`)
- **ไอเดีย 5:** event `intruder` (`count` `cm`) · `clear` (`count`) · `ack` (`by` = `app` หรือ `sw6`, `count`) · `armed` (`on` 0/1) · รับ `{"cmd":"ack"}`
- **ไอเดีย 7:** telemetry เพิ่ม `vib` (m/s², `null` ตอนเริ่ม) และ `vib_bad` (0/1) · event `{"id":"team05","event":"vib","bad":1,"vib":0.84}`
