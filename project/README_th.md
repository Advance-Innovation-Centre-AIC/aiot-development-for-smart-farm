# เรื่องโปรเจกต์ 25 เรื่อง (1 ทีม 1 เรื่อง)

ทุกไฟล์ต่อยอดจากไฟล์คาบที่รันได้แล้ว หัวไฟล์บอกว่า "ต่อยอดจาก" ไฟล์ไหน เปลี่ยนอะไร และทีมต้องแก้ 3 อย่างอะไรให้เป็นของตัวเอง · เกณฑ์ทุกตัวเป็น **ค่าสาธิตในห้องเรียน** ไม่ใช่คำแนะนำทางเกษตร

## กติกา

- **1 ทีม 1 เรื่อง** ห้ามสองทีมเลือกเรื่องเดียวกัน (22 ทีม 25 เรื่อง เหลือ 3 เรื่องสำรอง)

- ทุกเรื่องมี **จอบอร์ดและหน้าเว็บของตัวเอง** ออกแบบตามงานนั้น แต่ความยากใกล้เคียงกัน · ส่วนที่ต่อ WiFi/MQTT และกฎความปลอดภัยมาจากแม่แบบ 4 ตัว (A B C D) ที่ทดสอบแล้ว

1. คัดลอกไฟล์ไอเดียเป็น `g<เลขทีม>_<ชื่อโปรเจกต์>.py` เช่น `g05_mango_box.py` (เก็บไฟล์เดิมไว้เทียบ)

4. เปิดหน้าเว็บของเรื่อง: `project/web/idea_N.html?team=teamXX` (N = เลขเรื่อง 1-25) · รายชื่อทุกหน้าอยู่ที่ `project/web/index.html`
