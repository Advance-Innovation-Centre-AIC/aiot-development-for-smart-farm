# แนวทางอนาคต: Edge AI ในฟาร์ม (ไม่อยู่ในโจทย์โปรเจกต์รุ่นนี้)

สามไฟล์นี้ชี้ว่าคอร์สไปต่อทางไหนได้ ไม่ใช่งานที่ต้องส่ง และไม่ใช้ให้คะแนนโปรเจกต์รุ่นนี้
ทุกไฟล์ต่อยอดจาก `s3/sf3_04_ai_pump_doctor.py` (หาโมเดลด้วยชื่อ, เกณฑ์ความมั่นใจ, ยืนยัน 3 ใน 5)
และ `s3/sf3_06_ai_to_mqtt.py` (ส่งผล AI ขึ้น `bento-aiot/<TEAM>/ai`)

| ไฟล์ | แสดงอะไร | โมเดลที่ต้อง Deploy จาก Edge AI Store (ชื่อบนบอร์ด) |
|---|---|---|
| `ai_1_pump_anomaly.py` | ปั๊มสั่นผิดปกติ: กฎค่าสั่นจาก IMU กับ AI ตัดสินคู่กัน เห็นตรงกัน = เตือน ฝ่ายเดียว = ให้คนไปดู · ส่งตามข้อ 3.11 (`m` = `pump`) | `AnomalousVibration` (ไม่มี: ใช้ `Motion` ในตัว) |
| `ai_2_siren_alarm.py` | ฟังไซเรนหน้าฟาร์มจากไมโครโฟน เตือนบนจอ จอไฟ RGB และ MQTT ตามข้อ 3.10 (`alarm` + event) | `SirenDetection` (การ์ด Store ชื่อ `Siren` · ไม่มี: ใช้ `Siren Detection` ในตัว) |
| `ai_3_voice_command.py` | พูด go / stop เพื่อเปิด/ปิดปั๊มจำลอง ต้องกด SW6 ยืนยันก่อนทำ · event `voice_cmd` ตามข้อ 3.11 | `Voice Commands` (การ์ด Store ชื่อ `VoiceCommands`, Keyword spotting) |

ไม่พบโมเดล จอจะขึ้น "ต้อง Deploy โมเดลจาก Edge AI Store ก่อน"

## ก่อนรัน

- แก้ `WIFI_SSID` `WIFI_PASS` `TEAM` ที่หัวไฟล์ ยังไม่แก้ = ทำงานออฟไลน์ พิมพ์ผลลง Console
- ผล AI ใน BENTO Emulator เป็นผลจำลอง ต้องทดสอบบนบอร์ดจริง

## ทำไมไม่อยู่ในโปรเจกต์รุ่นนี้

- **โมเดลตัวอย่างไม่ได้ฝึกจากฟาร์มจริง** ปั๊ม ไซเรน และเสียงคนในฟาร์มต่างจากข้อมูลที่ใช้ฝึก งานจริงต้องเก็บข้อมูลและฝึกใหม่
- **ผลขึ้นกับ firmware และไมค์** โมเดล Voice Commands ทดสอบ 2026-10-10 ได้ 14/20 บน Dev Kit fw 2.5.1 และ 0/20 บน firmware รุ่นเก่ากว่า บอร์ดในห้องเรียนอาจยังไม่ใช่รุ่นเดียวกัน
- **Voice Commands มีคลาส `unlabeled left right up down stop go`** ไม่มี forward / backward ไฟล์นี้จึงใช้แค่ go กับ stop
- **ยังไม่ได้รันบนบอร์ด** สามไฟล์นี้ผ่านการตรวจไวยากรณ์และฟอนต์บนจอ แต่ยังไม่ได้รันบนบอร์ดจริงหรือ Emulator
