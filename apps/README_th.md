# ชุดแอปของกลุ่ม — แดชบอร์ดเว็บ/มือถือ + แจ้งเตือนเข้ามือถือ

บอร์ด TESAIoT Dev Kit ของกลุ่มทำหน้าที่เป็น **Smart IoT Gateway**: อ่านเซนเซอร์ ตัดสินใจ แล้วส่งค่าขึ้น MQTT broker สาธารณะ
ชุดนี้คือ "แอปตั้งต้น" สำหรับฝั่งคน: ใช้ได้ทันที และแก้ต่อเป็นแอปของกลุ่มเองในโปรเจกต์ (เสา 5)

ทุกหัวข้อ ทุกคีย์ JSON และทุกคำสั่งตรงกับสัญญาตัวจริง [`s2/app/MQTT_CONTRACT_th.md`](../s2/app/MQTT_CONTRACT_th.md) — ถ้าจะเพิ่มอะไร ให้เพิ่มในสัญญาของกลุ่มก่อน

| โฟลเดอร์ | คืออะไร |
|---|---|
| `web-dashboard/` | แดชบอร์ดบนเบราว์เซอร์ ใช้ได้ทั้งมือถือและจอโปรเจกเตอร์ ติดตั้งเป็นแอปบนหน้าจอมือถือได้ (PWA) |
| [`s3/app/notify/`](../s3/app/notify/README_th.md) | หน้าเว็บส่งแจ้งเตือนเข้ามือถือผ่าน ntfy (Telegram เลือกใช้ได้) เปิดค้างไว้บนโน้ตบุ๊กเครื่องเดียว มือถือเด้งแม้ปิดแดชบอร์ดแล้ว (ข้อ 6) |

## 1. เปิดแดชบอร์ด

**แบบออนไลน์ (ง่ายที่สุด):** เปิดบนมือถือหรือโน้ตบุ๊ก แล้วเปลี่ยน `team05` เป็นเลขกลุ่มของเรา

<https://advance-innovation-centre-aic.github.io/aiot-development-for-smart-farm/apps/web-dashboard/?team=team05>

**แบบแก้โค้ดเอง (ทำบนเว็บ GitHub ไม่ต้องติดตั้งอะไร):**

1. กด **Fork** repo ของคอร์สเข้าบัญชี GitHub ของกลุ่ม
2. ใน fork: **Settings → Pages →** Source = *Deploy from a branch* · Branch = `main` / `(root)` แล้วกด **Save**
3. แก้ไฟล์บนเว็บ GitHub (ปุ่มดินสอ) แล้วกด **Commit changes** · รอราว 1–2 นาที แล้วเปิด `https://<ชื่อบัญชี>.github.io/aiot-development-for-smart-farm/apps/web-dashboard/?team=team05`

ต้องเปิดผ่าน `https://` เท่านั้น ดับเบิลคลิกไฟล์ `index.html` ตรง ๆ (`file://`) จะใช้โมดูล JavaScript และการแจ้งเตือนไม่ได้ · แก้แล้วยังเห็นของเดิม ให้รีเฟรชแบบล้างแคช (Ctrl+Shift+R)

**เลือก broker:** ค่าเริ่มต้นคือ HiveMQ (`wss://broker.hivemq.com:8884/mqtt`) ถ้าผู้สอนประกาศให้ใช้ตัวสำรอง ให้เลือก Mosquitto (`wss://test.mosquitto.org:8081/mqtt`) ในหน้าแอป — ต้องตรงกับ `BROKER` บนบอร์ดเสมอ

## 2. ทดสอบโดยไม่มีบอร์ด

เปิดหน้าเว็บจำลองตัวใดตัวหนึ่ง (ไม่ต้องติดตั้งอะไร) ด้วยเลขกลุ่มเดียวกับแดชบอร์ด เช่น `team99` แล้วเปิดแดชบอร์ดด้วย `?team=team99`

| หน้าเว็บ | เล่นเป็นอะไร | เห็นอะไรในแดชบอร์ด |
|---|---|---|
| [`s2/app/fake_board.html`](https://advance-innovation-centre-aic.github.io/aiot-development-for-smart-farm/s2/app/fake_board.html?team=team99) (กด **เริ่ม**) | บอร์ดที่รัน `sf2_02` แล้ว `sf2_03` | การ์ดค่าฟาร์ม กราฟ ปุ่มสั่งปั๊มแล้วบอร์ดจำลองบอกในบันทึกว่ารับคำสั่ง แจ้งเตือนพืชหนึ่งครั้ง |
| **PLC Simulator** ใน [`s2/app/farm_web.html`](https://advance-innovation-centre-aic.github.io/aiot-development-for-smart-farm/s2/app/farm_web.html?team=team99) (กด **ต่อ** แล้ว **เริ่ม PLC Simulator**) | โหนดเซนเซอร์ในแปลง + PLC ปั๊ม | แผนผัง Gateway: ดิน ถัง และสถานะ PLC สด ๆ |

หรือรันไฟล์บอร์ดตัวจริงใน **BENTO Emulator** (ต่อ broker สาธารณะจริง) · อย่าเปิดตัวจำลองพร้อมบอร์ดจริงที่ใช้เลขกลุ่มเดียวกัน ข้อความจะปนกันจนแยกไม่ออก

## 3. ในแอปมีอะไร

| แท็บ | ใช้ทำอะไร |
|---|---|
| ภาพรวม | การ์ดค่าล่าสุด (ขึ้นเองเมื่อบอร์ดเริ่มส่งคีย์นั้น) + แผนผังฟาร์ม: โหนดเซนเซอร์ → Gateway (บอร์ด) → PLC → ปั๊ม พร้อมสถานะสด |
| กราฟ | กราฟเส้นย้อนหลังของดิน ถัง อุณหภูมิ และโหนดในแปลง |
| ควบคุม | เปิด/ปิดปั๊ม · เปิด/ปิดออโต้ของ Gateway · ส่งเสียงเรียก · รับทราบแจ้งเตือน — ส่งเฉพาะคำสั่งที่มีในสัญญาข้อ 4 |
| แจ้งเตือน | กฎเตือนที่แก้ได้ในหน้าแอป (เสียง · สั่น · แจ้งเตือนของเครื่อง) พร้อมช่วงเว้นกันเตือนรัว |
| บันทึก | เหตุการณ์ทั้งหมด + ดาวน์โหลดประวัติเป็น CSV เปิดใน Excel ได้ |

ปุ่มมุมบนสลับธีมสว่าง/มืด · ประวัติเก็บในเบราว์เซอร์ของเครื่องนั้นเอง ไม่ได้ส่งไปไหน

**ข้อจำกัดที่ต้องรู้:** แจ้งเตือนจากแดชบอร์ดทำงาน **เฉพาะตอนเปิดแอปค้างไว้** · ถ้าอยากให้มือถือเด้งแม้ปิดแอปแล้ว ใช้หน้าแจ้งเตือน `s3/app/notify/` (ข้อ 6)

## 4. ติดตั้งเป็นแอปบนหน้าจอมือถือ (PWA)

- **Android (Chrome):** เปิดลิงก์แอป → เมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก** (บางเครื่องมีปุ่มติดตั้งมุมบนของแอปให้กดเลย)
- **iPhone (Safari):** เปิดลิงก์แอป → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- การขออนุญาตแจ้งเตือนต้องเปิดผ่าน **https** (ลิงก์ GitHub Pages ข้างบน) หรือ `http://localhost` เท่านั้น
- บน iPhone ถ้าไม่เห็นปุ่ม "อนุญาตแจ้งเตือน" ให้ติดตั้งเป็นแอปบนหน้าจอโฮมก่อน แล้วเปิดจากไอคอนนั้น (Safari ให้ขอแจ้งเตือนได้เฉพาะเว็บแอปที่ติดตั้งแล้ว)

## 5. แก้ต่อเป็นแอปของกลุ่ม — แก้ไฟล์เดียว `web-dashboard/js/config.js`

| อยากได้ | แก้ตรงไหน | ตัวอย่าง |
|---|---|---|
| การ์ดใหม่ | `CARDS` เพิ่มหนึ่งบรรทัดต่อหนึ่งคีย์ของ telemetry | คีย์ `light` ของ `sf2_02` เป็นการ์ดมีหลอด 0–100 |
| กราฟใหม่ | `CHARTS` เพิ่มชุดข้อมูล (`src` = หัวข้อ, `key` = คีย์ JSON) | กราฟ `rh` เทียบ `temp_c` |
| กฎเตือนใหม่ | `DEFAULT_RULES` หรือกด "เพิ่มกฎ" ในแท็บแจ้งเตือน | `{ name: "ถังต่ำ", src: "telemetry", key: "tank", op: "<", val: 20, cool: 120, level: "warn" }` |

ชื่อคีย์ต้องสะกดตรงกับที่บอร์ดส่งทุกตัวอักษร (ดูสัญญาข้อ 3) · ลำดับคีย์ในข้อความจริงสลับได้ แอปจึงอ่านด้วยชื่อคีย์เสมอ

**แอปนี้ช่วยเสาไหนของโปรเจกต์ (ตาม README หลัก):**

| เสา | ในชุดนี้ |
|---|---|
| 1. Smart HMI | หน้าจอบอร์ดคือ HMI หลัก · แดชบอร์ดคือ HMI ตัวที่สองบนมือถือ ใช้แบบการ์ดและสีสถานะเดียวกัน |
| 2. เซนเซอร์ | การ์ดและกราฟของค่าที่บอร์ดอ่าน (อุณหภูมิ ความชื้น ความกด การเอียง) และโหนดในแปลง |
| 3. ปุ่มตั้งค่า | ค่าจากลูกบิดจำลอง (`sim`) แสดงแยกให้เห็นว่าไม่ใช่เซนเซอร์จริง · เกณฑ์เตือนในแอปตั้งเองได้ |
| 4. เสียง | เสียงเตือนในแอป + ปุ่มสั่งบอร์ดส่งเสียงเรียก (`beep`) |
| 5. MQTT + แอปของตัวเอง | ทั้งชุดนี้ — ต่อ broker ฟังทุกหัวข้อของกลุ่ม และสั่งกลับทางหัวข้อ `cmd` |

## 6. แจ้งเตือนเข้ามือถือแม้ปิดแอป — หน้าเว็บ `s3/app/notify/`

1. ติดตั้งแอป **ntfy** บนมือถือ (Android / iPhone)
2. บนโน้ตบุ๊กที่จะเปิดค้างไว้ เปิด <https://advance-innovation-centre-aic.github.io/aiot-development-for-smart-farm/s3/app/notify/index.html?team=team05> แล้วเปลี่ยน `team05` เป็นเลขกลุ่มของเรา
3. กด **สุ่มชื่อใหม่** ได้ชื่อหัวข้อ ntfy ที่ยาวและเดายาก — ชื่อนี้ **คือรหัสผ่าน** ใครรู้ชื่อก็อ่านแจ้งเตือนได้ · ในแอป ntfy กด **+** วางชื่อนั้นแล้ว Subscribe
4. กด **ส่งทดสอบ** ให้มือถือเด้งก่อน แล้วกด **เริ่มส่งแจ้งเตือน** · ติ๊ก **ลองเฉย ๆ (dry-run)** ถ้าอยากดูว่าจะส่งอะไรโดยไม่ส่งจริง · หน้าเว็บมีช่วงเว้นและเพดานต่อชั่วโมงเอง เพราะ ntfy.sh จำกัดจำนวนข้อความต่อวัน
5. (ไม่บังคับ) Telegram: ใส่ bot token และ chat id ในหน้าเว็บ — token ห้ามอยู่ในไฟล์หรือในแชตกลุ่ม

หน้าเว็บนี้ต้อง **เปิดค้างไว้บนเครื่องที่ต่อเน็ต** ปิดแท็บ ปิดเครื่อง หรือเครื่องหลับเมื่อไร แจ้งเตือนก็หยุด · วิธีใช้ละเอียด: [`s3/app/notify/README_th.md`](../s3/app/notify/README_th.md)

## 7. Vibe coding — ให้ AI ช่วยต่อยอดจากสัญญา

วางเนื้อหา `MQTT_CONTRACT_th.md` ให้ผู้ช่วยเขียนโค้ดอ่านก่อน แล้วพิมพ์คำขอทีละข้อ ทุกครั้งที่ได้โค้ดมา **ลองกับ `fake_board.html` หรือ PLC Simulator ใน `farm_web.html` (ข้อ 2) ก่อนใช้กับบอร์ดจริง** และอ่านให้เข้าใจทุกบรรทัดก่อนส่งงาน

1. **น้ำต่อวัน:** "จากสัญญานี้ เพิ่มการ์ดในแดชบอร์ดที่รวมเวลาที่ `pump` = 1 ของวันนี้เป็นนาที แล้วคูณอัตราไหล 0.5 ลิตร/วินาที เป็นลิตรที่ใช้วันนี้ เริ่มนับใหม่ตอนเที่ยงคืน"
2. **ไทม์ไลน์ปั๊ม:** "ทำกราฟแท่งแนวนอนแสดงช่วงเวลาที่ปั๊มเปิดในหนึ่งชั่วโมงล่าสุด จาก telemetry `pump` และ `plc/state` ของสัญญานี้ แยกสีตาม `why`"
3. **ตัวชี้วัดโลจิสติกส์:** "เพิ่มการ์ด 'เวลาตอบสนอง' = วินาทีจากตอนดินต่ำกว่าเกณฑ์ ถึงตอน `plc/state` รายงาน `pump` = 1 เก็บค่าเฉลี่ยของวันนี้ และส่งออกเป็น CSV"
4. **แผนที่ฟาร์ม:** "วาดผังแปลงเป็น SVG มีโหนดดิน ถัง Gateway และ PLC ตามตำแหน่งจริงของฟาร์มกลุ่มเรา แต่ละโหนดเปลี่ยนสีตามค่าล่าสุด และเป็นสีเทาถ้าไม่ได้ยินเกิน 15 วินาที"
5. **แจ้งเตือนกลุ่ม:** "แก้หน้าแจ้งเตือน `s3/app/notify/index.html` ให้ส่งสรุปเข้า ntfy ทุกเช้า 7 โมง: ค่าต่ำสุด/สูงสุดของดินและอุณหภูมิเมื่อวาน จำนวนครั้งที่ปั๊มเปิด และแจ้งเตือนที่ยังไม่มีใครรับทราบ (หน้านี้เปิดค้างไว้ทั้งคืน จึงจดค่าของเมื่อวานไว้ในเบราว์เซอร์เอง)"

## 8. ความเป็นส่วนตัวและความปลอดภัย

- broker สาธารณะและ ntfy.sh **ใครก็อ่านได้** — ห้ามส่งชื่อคน เบอร์โทร ตำแหน่งบ้าน หรือรหัสผ่านใด ๆ ผ่านหัวข้อของกลุ่ม
- ใครก็ **ส่งคำสั่ง** เข้าหัวข้อ `cmd` ของกลุ่มเราได้ — กฎความปลอดภัยจึงอยู่บนบอร์ด (ปั๊มไม่เกิน 30 วินาที · ถังต่ำไม่เปิด) ไม่ใช่ในแอป
- แอปฟังเฉพาะหัวข้อของกลุ่มตัวเอง ไม่ฟังทั้ง broker
